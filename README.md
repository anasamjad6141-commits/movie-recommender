# Movie Recommendation System

A **Flask-based web application** that provides personalized movie recommendations. The system predicts which movies a user might like based on movie attributes such as genre, rating, duration, and release year using **Logistic Regression**.

## Features
- Search for a movie and get recommendations of similar movies.
- Recommendations are based on the selected movie's genre and predicted user preference.
- Simple and interactive web interface using Flask and HTML templates.

## Technologies Used
- Python 3
- Flask
- Pandas
- NumPy
- Scikit-learn (Logistic Regression)
- HTML/CSS (for frontend)
